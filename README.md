# Academic PhD Website

## GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload all files in this folder to the repository root.
3. Go to Settings -> Pages.
4. Choose Deploy from a branch, branch `main`, folder `/ (root)`.
5. Save. Your site will be at `https://YOUR-USERNAME.github.io/`.

Replace `Your Name`, `Your University`, email, research text, publications, presentations, and links. Replace `cv/CV.pdf` with your actual CV.
